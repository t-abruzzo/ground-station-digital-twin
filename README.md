#AWS Ground Station Digital Twin

A cloud-based satellite ground station simulator designed to demonstrate architecture, automation, and operationsl workflows of a modern satellite ground system.

The system is being built incrementally using Linux, Python, AWS, Kubernetes, Terraform, and C++.

#Project Goals
* Build a functional satellite ground station digital twin
* Demonstrate Linux system administration and automation
* Build backend services using Python
* Deploy cloud infrastructure using AWS
* Manage infrastructure as code with Terraform
* Containerize and orchastrate services with Kubernetes
* Use C++ where lower-level or performance-oriented components are appropriate
* Develop an operational interface for monitoring satellite and ground-station activity
* Practice designing a production-style cloud architecture 

#Planned Capabilities
* Satellite telemetry
* Ground station status
* Satellite-to-ground communication
* Contact scheduling
* Contact initiation and termination
* Satellite command submission
* Scheduled commands
* Command execution
* Command receipt verification
* Ground station and satellite health/status monitoring
* Automated system checks and logging
